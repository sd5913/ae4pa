## V4 目标范围

- 仍是五层、三卡双槽、五怪、309 救援和五楼逃脱，主角只左右移动。
- 1F 经理对话后可上楼；保洁、保安、经理卡随任务取得，并用于清理、取件和批准。
- 单个限时任务接受后计时；对白、手册、背包和暂停停表，楼梯支持合法回访。
- 剧情任务完成才开通路；普通门违规警告并退回安全点；被员工发现或超时恢复任务检查点。
- 三卡背包不扩展为通用物品背包；任务文件只记录状态。不开战斗、跳跃、追逐或客房内部。

详细行为、五任务流程和仍待审阅的建议见主策划。下面的运行方式描述当前代码，不代表 V4 已可玩。

## 如何打开当前项目

1. 用 GitHub Desktop 克隆共同仓库；已有本地副本时先检查并保留自己的未提交修改。
2. 打开 Godot 项目管理器，选择“导入”，定位到仓库中的 `project.godot`。
3. 进入编辑器后核对 Godot 版本为 4.7.2。首次资源导入产生的 `.godot/` 缓存由本机生成，不提交。
4. A 分支按 F5 运行 `scenes/main.tscn`：E／鼠标继续真实序章；结束后 A/D 行走，到 1F x2400 的经理附近按 E 交谈，再去右端楼梯 E 上 2F。共享 main 尚未合入 A 功能时仍是旧公共走廊。Mac 可双击 `.tscn` 后按 Command+R 运行当前场景。
5. F6 运行当前测试场景。各成员的入口见 [组员接入说明](docs/onboarding.md)。

F6 的 `scenes/tests/core/task_01_core_test.tscn` 保留任务 01 开发按钮：代记经理、接受任务、代记清洁；它不播放正式序章。真实 201 会自动介绍任务，清洁完成后回 201 按 E 交付才解除 x1250 路障。代记操作不算正式主线验收，被抓／超时后重试仍禁用。F5 主入口已移除代记经理按钮；core_test 继承该主入口。接线见 [接口增量](docs/interfaces.md#16-序章与经理对白正式接线2026-11-12)。五层预览仍可 F6 运行 floors_test；B 正面失败仍待交付。

不要为个人功能另建一套 Godot 项目。运行入口和验证方法随底座完成更新到本文件。

五层实际场景已挂载对应背景。独立接入预览可 F6 运行 `scenes/tests/core/floor_art_preview.tscn`。A/D 或方向键行走，1—5 或顶部按钮换层，“显示当前主线接入点”可对照现有房门／员工／污渍坐标。预览使用 `assets/backgrounds/floor_1.png` 至 `floor_5.png`，按透明内容区域取景、等比显示为 3600 宽，脚底对齐 y560；占位主角在预览里放大 2.4 倍用于比例观察。原图中的人物、开门与灯光状态是静态绘制，正式可玩接入还需拆分这些图层、对齐交互位置并补齐 3F 的 305 和 5F 的 504／505。

## 协作流程

每次开始先检查当前分支和修改清单、保留已有工作，再同步已发布的最新 main。在自己的模块和独立测试场景开发；完成后写清改动、实际测试和 A 需要接入的位置，再提交 PR。A 每接入一个模块就回归已有功能，main 只接收可运行的版本。

跨模块修改先明确范围和接口；不得通过复制卡片数据、另建管理器或重写他人模块绕过接入问题。当前按编号逐项推进，具体任务见 [执行清单](PLANS.md)。
