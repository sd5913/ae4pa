# 一楼分区分层美术包

只交付一楼美术，存放于 C 个人分支；未替换游戏场景，未合并 main。

- 原图画布 3840×2160，可见区域 `(0,806,3840,548)`；工作画布为 3840×548。
- 入口 / 前台 / 休息区 / 保洁间 / 楼梯间分别从原尺寸分区编辑，再按原坐标拼接。没有将整栋楼缩小后放大。
- `01_far_background`：五块去人物、去家具的建筑底图。窗外景、墙面、窗框和楼梯保留在此层。
- `02_floor`：三块连续原尺寸红毯、三块可独立调整的踢脚线、下沿平台。
- `03_back_furniture`：前台、钥匙柜、旗帜、钟、双椅、桌、盆栽、储物架、柜子、保洁车、书、服务铃和各灯具。物件之间及镂空为真实 Alpha。
- `04_foreground`：左 / 中 / 右前景柱，可独立调整遮挡关系。
- `05_light_fx`：可重复实例化的暖光、灯光锥、接触阴影，均为真实 Alpha。绘画本身的环境明暗及灯罩发亮颜色仍保留，附加光晕 / 投影可独立关闭。

## 可编辑源文件

`art_sources/floor_1/floor_1_layers.ora` 是真正的 OpenRaster 分层源文件，可用 Krita 或 GIMP 打开，每块底图、每个物件、每个光效 / 阴影实例都是独立有名称的图层。源文件保留原图可见区坐标，不含静态人物图层。层序把接触阴影放在家具下方、光晕放在家具上方。

`manifest.json` 记录每张 PNG 的尺寸、原图 / 工作区坐标、SHA-256、Alpha 统计及示例摆放。使用左上角锚点，缩放 1；若使用 Sprite2D，设 centered=false。统一整体变换，关闭自动裁边与独立缩放。背景接缝位于结构分区边界，可由独立柱遮挡；不要把各区单独缩放成不同高度。

## 来源与限制

原始输入是扁平 PNG，并非可恢复的原始 PSD。使用内置 imagegen 对每个区域及物件单独去人 / 补绘 / 提取，随后确定性裁切、注册和打包。人物及家具原先遮住的内容属于重建，纹样、轮廓、部分窗位存在细节差异，不声称逐像素还原。入口小盆栽复用一个提取件。真实提示词保存在源文件目录的 prompts.json。

游戏 PNG 采用无损 RGBA；美术源文件用 .gdignore 排除引擎扫描。此次只核对美术资源与源文件结构，未代记主线接入或真人游戏验收。
