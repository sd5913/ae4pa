# Monster dialogue half-body portraits v1

Five individual 1024 x 1536 RGBA PNGs, generated with built-in image_gen from the supplied Terese style reference and approved monster lineup. Original generated alpha preserved without re-encoding or background replacement.

Each image has genuine fully transparent pixels outside the character. The PNG RGB data may contain hidden dark colours under alpha=0; render with alpha blending. These are waist-up dialogue assets, not animation sheets.

Source prompts and alpha checks: `../../../art_sources/monster_dialogue_portraits_v1/`. Runtime dialogue scenes are not modified by this asset delivery.
