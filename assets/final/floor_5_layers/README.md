# 五楼游戏PNG（无房门、无人物）

本目录共31张PNG，坐标母版7680×1500，地面基线y1340。位置、尺寸、来源、缩放和SHA-256见 `layout.json`。

- `01_far/`：外景/月亮、酒红墙纸护墙板、完整左黑柱、整体楼梯、双窗、5F牌、屋顶中央徽章与扇形窗、可拼接檐口栏杆及扶手顶条、柱头、空出口及整体平台；另有4块1920×1500的连续建筑底图。
- `02_ground/`：独立可拼接地毯和踢脚线。
- `03_furniture/`：无接待员离店登记台（含钥匙格和台面用品）、红扶手椅、灯桌、盆栽、留声机柜、城堡画、百合花瓶、酒店徽章、三球吊灯、壁灯，均为真实Alpha PNG。
- `04_lighting/`：独立暖光及接触阴影。

可按编号将四块建筑底图放在x0/1920/3840/5760，叠加地面/家具/光效；也可直接使用独立建筑组件重组。不要在同一位置重复叠加建筑底图和对应独立组件。房门位置是连续墙面，等待已有501—503门组件覆盖，门宽高比例和游戏交互以后续场景接入为准。
