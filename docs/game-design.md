## 1 项目目标和规模

主角潜入五层怪物旅馆，在一楼从工作人员背后偷到三张员工 ID，观察房门和五种怪物的规则，在三楼 309 救出闺蜜，再到五楼消防出口逃离。

| 项目 | 首版目标 |
|---|---|
| 类型 | 单人、纯 2D 横向、观察与身份切换、轻度潜行解谜 |
| 场景规模 | 5 层旅馆走廊，逐层向上，不自由穿梭所有楼层 |
| 核心对象 | 3 张 ID、2 个佩戴槽、5 类房门怪物、3 名人类员工、1 位闺蜜 |
| 核心循环 | 观察 → 选卡／等待 → 安全通过 → 到达本层目标 |
| 体验目标 | 预警清楚、失败原因明确、观察比反应速度重要、失败后快速重试 |
| 技术 | Godot 4.7.2 标准版、GDScript、Compatibility，1280×720 逻辑画面 |

明确不制作：战斗、血条、跳跃、上下移动、攀爬、追逐／寻路 AI、进入客房、复杂物理机关、Boss、多结局、升级／商店、随机地图和联网多人。

## 3 世界观和故事流程

“夜班旅馆”白天普通、深夜接待怪物。人类员工在一楼工作，二楼以上为怪物客房。保安、保洁、经理的 ID 能让对应住客把主角暂时当作员工。

闺蜜应聘夜班后被登记为“不可离店员工”，被困在三楼 309。主角收到求救消息后潜入。救援完成后，下楼通路封锁，两人继续上到五楼，经室外消防连廊逃脱。

开场采用约 1—2 分钟的静态画面／文字，可跳过：

1. 手机消息：“他们不让我离开……我在309号房。”
2. 旅馆外景，主角决定进入。
3. 一楼广播：“员工请佩戴有效ID卡。”
4. 两页员工须知：操作与三卡、五怪应对。
5. 进入 1F，开始移动与 E 交互教学。

309 至少两句对白：“你终于来了！”“下面的路被封了，五楼有紧急出口！”逃脱后：“我们终于出来了！”不扩展对话树或分支剧情。

## 4 场景和输入

每层是单独的横向长走廊：左侧入口 → 员工或房门 → 右侧楼梯／目标。人物只沿固定水平线移动，松开方向键立即停止，镜头只沿水平方向跟随。楼层之间用淡入淡出，不要求电梯或楼梯动画。

| 动作名称 | 按键 | 目标行为 |
|---|---|---|
| move_left | A／左箭头 | 左移 |
| move_right | D／右箭头 | 右移 |
| interact | E | 偷取、救援、楼梯、出口 |
| switch_id | Q | 在两个佩戴槽之间切换当前卡 |
| open_bag | I | 打开三卡背包、调整两个佩戴槽 |
| open_help | H | 查看同一份操作与怪物手册 |
| pause | Esc | 暂停／菜单，目标包含继续、重试本层、回菜单 |

偷卡目标为按住 E 约 0.8 秒，救援和出口为按一次。背包具体布局、是否暂停、长按取消和多个交互目标的选择方式，在相应功能阶段由负责人共同确认。

当前原型步行速度为 160 像素／秒。正式楼层长度、门坐标和节奏需实际试玩；现有 2800×720 测试走廊只用于底座和组件接入。

## 5 三张 ID 和两个佩戴槽

| 卡片 | 公共标识 | 获得方式 | 唯一保护效果 |
|---|---|---|---|
| 保安 ID，蓝色 | SECURITY | 1F 保安背后偷取 | 独眼客检查时安全 |
| 保洁 ID，绿色 | CLEANER | 1F 保洁员背后偷取 | 长鼻客检查时安全 |
| 经理 ID，紫色 | MANAGER | 1F 经理背后偷取 | 礼帽客检查时安全 |

卡片不赋予技能、速度或开房权限，不能克制大耳客和核验客。

- 第一张进入槽 A，第二张进入槽 B，第三张留在背包；始终最多佩戴两张，当前只生效一张。
- Q 切当前槽，I 调整佩戴槽；替换下来的卡回背包，不丢弃、不重复获得。
- 玩家不用离开楼层寻找工作台即可调整装备，不做通用物品／掉落系统。
- 三卡集齐才允许从 1F 上 2F；缺卡时给出明确提示。
- 三卡集齐时提示：“已有三张卡，最多同时佩戴两张，按 I 更换。”
- “卡片不丢失”指获得后在后续楼层持续拥有；1F 失败重新偷三卡是明确的教学重试例外。
- 卡片真实数据只在 B 的 CardManager 中保存；Player、HUD、背包和房门读取同一份状态。

核验客开门且主角在其范围内时，Q 切换和背包装备替换都属于危险操作；单纯打开背包、空槽和无效操作的具体边界在功能阶段补充。

## 6 1F 工作人员和偷窃

保安、保洁、经理共用员工组件，只改岗位、位置、转向参数和素材。员工固定站位、左右转身，不巡逻、不攻击。

原型起点为约每 3 秒转向一次，转身前约 0.4 秒有可见提示；实际节奏可调整。靠近约 55 像素时显示交互提示。员工朝右时玩家应在其左侧，朝左时玩家应在其右侧；在背后按住 E 约 0.8 秒完成偷取，期间主角站定。

正面尝试偷卡，或偷卡过程中员工转回头看到玩家，立即报告 STAFF_CAUGHT。成功后显示获得对应 ID，员工上的卡标记为已取，不能重复领取。距离边界、松键和移动输入导致的取消方式在 B 与 A 接入时统一。

## 7 五种怪物共用一种房门

统一检测条件：游戏正在游玩、房门为 OPEN、主角在该门的水平检测范围内。门关闭或预警、主角在范围外时，不进行怪物失败判定。

| 怪物 | 标识 | 危险行为和失败条件 | 应对 | 视觉提示 |
|---|---|---|---|---|
| 独眼客 | EYE | 当前卡不是 SECURITY | 保安卡或等关门 | 大眼睛、蓝色眼睛图标 |
| 长鼻客 | NOSE | 当前卡不是 CLEANER | 保洁卡或等关门 | 大鼻子、绿色鼻子图标 |
| 礼帽客 | HAT | 当前卡不是 MANAGER | 经理卡或等关门 | 礼帽、紫色帽子图标 |
| 大耳客 | EAR | 在范围内仍移动 | 停步，等门关再走 | 大耳朵、黄色声波图标 |
| 核验客 | CHECKER | 在范围内主动切卡／更换佩戴槽 | 提前选卡，门前不换证 | 放大镜／夹板、白色证件图标 |

所有怪物只在门内露出立绘，不离开门、不追捕。前三类持续读取当前卡，大耳客读取移动状态，核验客响应实际换卡通知。普通行走不触发核验客；HUD 刷新不能伪造换卡。

首次遇见各怪物时给出可关闭短提示，图鉴造型和门口造型一致；不能仅靠颜色区分。当前移动原型以实际位移报告 is_moving，同时按左右键抵消；边界上按键与大耳客的最终判定由 A/C 接入时确认。

## 8 房门计时与公平规则

| 状态 | 原型时长 | 表现和规则 |
|---|---|---|
| CLOSED | 先用 5.5 秒；平衡参考 4.5—6.5 秒 | 房门关闭，可安全经过 |
| WARNING | 1.4 秒 | 门框闪烁／变色，提示即将开门；此时不判怪物失败 |
| OPEN | 2.8 秒 | 显示怪物，进入范围后按对应规则检测 |

按 CLOSED → WARNING → OPEN → CLOSED 稳定循环，不无预警地突然开门。同层门用不同初始相位错开，首版房号、怪物位置和计时方案固定，便于复现。完成主流程后才考虑进入楼层时从 2—3 套预设相位中选一套，不随机生成房间。

检测半径原型为门中心左右各 90 像素。前一扇门检测区结束和后一扇门检测区开始之间，建议至少留 120 像素安全空间。首次大耳／核验尽量单独出现；玩家选错卡时应能退回安全区等待。

预警不能只靠声音。房门编号、类型、半径、三段时长和 offset 可由 A 在 C 的同一个组件上配置，不复制五份怪物程序；具体字段名见公共接口。

## 9 五层逐步流程

| 楼层 | 场景与顺序 | 本层目标与离开条件 |
|---|---|---|
| 1F 大堂 | 保安 → 保洁员 → 前台经理；正式 1F 没有怪物 | 学移动和交互，偷齐三张 ID，再按 E 上楼 |
| 2F 入门 | 201 独眼 → 202 长鼻 → 203 大耳 → 204 礼帽 → 205 核验 | 逐个认识五怪；204 学会换入经理卡；到右端上 3F |
| 3F 救援 | 301 长鼻 → 302 独眼 → 303 核验 → 304 礼帽 → 305 大耳 → 309 闺蜜 | 309 按 E 触发对白和救援，完成后才能上 4F |
| 4F 结伴 | 401 大耳 → 402 独眼 → 403 礼帽 → 404 核验 → 405 长鼻 | 闺蜜跟随，稍增密度，不增加新技能；到右端上 5F |
| 5F 逃脱 | 501 礼帽 → 502 长鼻 → 503 核验 → 504 独眼 → 505 大耳 → EXIT | 综合使用旧规则，出口按 E 触发结局 |

1F 建议 3—5 分钟，2F—4F 每层约 3—4 分钟，5F 约 3—5 分钟，都是体验参考而非强制计时。

309 完成后 has_friend 变为 true。闺蜜以主角后方约 40 像素的距离跟随，转向时切换跟随侧；不做独立碰撞、寻路、被抓或失败判定。换层后在主角附近继续显示。

5F 不增加密码、钥匙、Boss 或隐藏结局。可用门贴图切换及短淡出，随后显示两人逃脱与 ESCAPED。

周末小样使用独立测试走廊容纳保安和独眼门，不改变正式 1F 无怪物的规则。

## 10 状态、失败和重试

目标状态流程为 MENU → INTRO → PLAYING → RESCUE_DIALOGUE → PLAYING → WON。任何 PLAYING 阶段都可能进入 FAILED。底座目前只实现 MENU／PLAYING／FAILED，其余随功能接入。

| 失败标识 | 界面解释 |
|---|---|
| STAFF_CAUGHT | 偷窃被发现 |
| WRONG_CARD | 当前工作证不符合要求 |
| MOVED_NEAR_EAR | 大耳客开门时仍在移动 |
| SWITCHED_NEAR_CHECKER | 核验客面前更换工作证 |

一次失败只处理一次，停止游玩输入和怪物检测，失败界面仍能响应按钮。显示 CAUGHT!、明确原因和“重试本层”，不强迫回标题或重看剧情。

重试回当前楼层入口，重置房门初始相位；1F 清空该轮收集并重新偷卡，2F—5F 保留已获得三卡。救援后进入 4F／5F 必须保留闺蜜状态。

原文同时包含入口故事快照和保留救人进度，3F 救人后的“本层”重试及装备槽恢复顺序继续列为待确认。A/B/D 在重试／救援功能开发时统一后写入接口与 QA，不各自选择默认行为。首版只要求会话中的楼层重试，不扩展账户和云存档。

## 11 UI 与最小剧情内容

| 界面 | 必须让玩家知道什么 |
|---|---|
| 主菜单 | 游戏名、开始、说明；Windows 可提供退出 |
| 操作／图鉴 | 第一页操作和三卡，第二页五怪应对；H 复用同一份内容 |
| HUD | 楼层、当前任务、两槽、当前生效卡高亮 |
| 背包 | 拥有的三卡与两槽，向 B 的接口发出替换请求 |
| 交互提示 | 靠近目标才显示 E；偷卡成功有反馈 |
| 失败页 | CAUGHT!、一句原因、Retry |
| 救援对白 | 说明找到了闺蜜及继续上五楼的原因 |
| 通关页 | ESCAPED、两人逃出、总时长／失败次数、重新开始／返回菜单 |

通关统计是策划目标，当前代码尚未提供计时和失败次数字段，A/D 接入时补充公共接口。当前 DeveloperOverlay 只是底座调试显示，不算正式 HUD 或菜单。

不做复杂背包数量、强化、导航地图和技能冷却 UI。所有页面用 Godot UI 实现；背包和暂停方式按功能阶段确认。

## 12 共享美术与声音

首版画面为平面 2D，优先轮廓清楚、比例一致、规则可辨认。全员共同生成和选择候选图，使用该素材的功能负责人裁切、命名并导入。

| 类别 | 最低需求 | 接入者 |
|---|---|---|
| 主角、闺蜜 | 各站立 1 张，走路两帧可后补 | A |
| 工作人员 | 保安、保洁、经理各 1 张，可水平翻转 | B |
| 怪物 | 五类各 1 张头像／半身图 | C |
| 房门 | 共用关／预警／开的一套表现 | C |
| 背景 | 先大堂和一条客房走廊，五层可换色与门牌；外景按剧情需要补 | A |
| UI | 三卡、五怪图标、对白框和按钮 | D |
| 音效 | 开门、预警、偷卡、失败、通关；可后补 | 使用者 |

资源放 assets/final/ 对应目录，使用小写英文和下划线文件名，常用透明 PNG。候选原图不整套进仓库，正式素材记录来源和许可／生成工具。

层级从后到前：走廊背景 → 门底图 → 怪物 → 门框／预警 → 主角／闺蜜 → HUD。不做透视、骨骼动画或复杂灯光；静音仍能理解全部规则。

## 13 模块和开发边界

| 模块 | 职责 | 负责者 |
|---|---|---|
| Player | 位置、移动、朝向、移动锁、横向相机 | A |
| GameManager／Level | 新局、状态、失败、换层、救援、重试、通关 | A |
| Staff | 转向、偷取条件与过程、成功反馈 | B |
| CardManager | 三卡所有权、两槽、当前卡和变化通知 | B |
| Door | 同一组件的计时、范围和五怪检测 | C |
| UI／剧情／QA | 页面、显示、操作请求、对白、测试记录 | D |

A 配置两个 Autoload、组装 B/C/D 组件。公共名称、函数、信号和当前可用状态统一见公共接口文档，不能在主策划中复制另一套签名。

先完成“主角 → 偷一张卡 → 独眼门 → 成功／失败重试”的最小闭环，再补齐三卡五怪，随后五层与救援，最后换图和交付。各成员可以在公共接口下并行开发独立组件，主场景由 A 按依赖逐项接入。

## 14 完整作品验收

最终应能从菜单进入游戏，1F 偷三卡，2F—5F 按五怪规则前进，309 救出闺蜜并持续跟随，失败有明确原因且可本层重试，5F EXIT 进入结局。

具体操作、预期结果和测试状态由 [QA 清单](qa.md) 的 T01—T14 维护；全员至少完整试玩一次。交付物为可运行游戏、GitHub 源项目、操作说明、截图和 1—3 分钟演示视频；Windows／Web 的课程硬性要求由 A 最终核实。

时间不足时先减少人物／怪物动画、装饰、随机相位、复杂声音和多页剧情。保留左右移动、背后偷卡、三卡双槽、五怪、清楚预警、309 救援、五楼出口和失败重试。
