## 范围和行为

- 奶油正文框、金边、独立姓名牌、正文与姓名牌稳定位置都来自标准剧情组件。Carol 使用同一人物槽和比例布局。姓名牌在角色切换时不跳动。
- 无继续按钮；怪物对白无序章跳过按钮。使用原 StoryPointer 的 E、鼠标点击／拖动／回显处理；任务条件、计时、发卡、交付成功守卫及完成信号不变。
- 对话期间暂时降低提示的透明度，结束／取消／隐藏后恢复原透明度，不重写其 visible 状态。
- 覆盖201—205的既有初见、缺证、工作中、待交付、交付后和完成回访数据；只统一现有入口，不新增尚未接线的回访玩法。302登记介绍、403／501初见／提醒／成功通过准确对白ID共用同一组件。
- 怪物JSON的全部既有台词补入英文目录；不改变中文剧本内容。
