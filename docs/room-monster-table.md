## 配置口径

- 表中怪物 ID 与卡片 ID 均按 [公共接口](interfaces.md) 的大小写原样书写：`EYE`、`NOSE`、`HAT`、`EAR`、`CHECKER`；`SECURITY`、`CLEANER`、`MANAGER`。
- `CLOSED` 和 `WARNING` 状态不做怪物失败判定；五类怪物的判定只在 `OPEN` 且主角处于门的检测范围内按策划案规则执行。
- 表中楼层顺序来自主策划 §9，不代表已确定门间距、场景坐标或各门计时。具体配置由 A 在同一门组件上设置；未确认项请勿从相邻房号推算。
- 1F 不在本表：主策划 §9 明确正式 1F 没有怪物。
