## 2. 游戏定位和目标

这是一个单人 2D 横向潜行解谜游戏。玩家扮演女主，在五层怪物旅馆中寻找闺蜜Terese，利用偷来的员工工作证冒充工作人员，通过怪物提出的工作要求，取得通行条件，在三楼 309 救人，最终从五楼消防出口逃离。

核心循环：

> 观察门内怪物 → 被剧情怪物拦截 → 接取限时任务 → 准备工作证和装备 → 使用正确身份完成真实工作 → 返回对应怪物交付 → 解锁通路／后续任务。

普通门的循环则是：观察预警和怪物 → 提前准备身份，或停步等待 → 安全经过。普通门不要求每次重新做任务。五种教学交付后，相应规则会写入H笔记；三楼以上靠近实际预警／开门怪物时出现一次短复习，离开该门即隐藏，违规退回说明实际原因。

**主线路线为二楼五项教学 → 三楼登记 → 309 救援 → 403 巡房记录交付 → 501 离店单批准并交付 → EXIT。** 自动化已从正常新局连跑八项任务和真实重逢 CG，完整真人通关待验收。结局使用现有成功页，额外结局 CG 与统计待制作。

## 3. 操作与交互

| 操作         | 当前功能                        |
| ---------- | --------------------------- |
| A／D 或左右方向键 | 水平移动                        |
| E          | 对话、接近工作点交互、交付、楼梯等；偷证和清理需要长按 |
| Q          | 在两个装备槽之间切换当前生效身份            |
| I          | 打开背包，查看持有证件和替换装备槽           |
| H          | 打开操作说明／调查笔记                 |
| Esc        | 打开暂停界面                      |
| HUD 工具栏    | 提供背包、笔记、暂停、任务信息等入口          |

楼梯地面标出实际70px交互区与方向；走入后显示目的地或未解锁原因，楼层许可保持原规则。

角色不跳跃、不战斗。对白和菜单打开时，世界交互受限制，任务计时停止。关键信息应同时通过任务详情、HUD 当前目标和交互反馈提示，而不只依赖玩家记住一段对白。

## 4. 三张工作证与两个装备槽

三种身份是保洁（`CLEANER`）、保安（`SECURITY`）、经理（`MANAGER`）。三个证件来源员工目前都在一楼。

- **持有**：玩家已经获得这张卡。最多持有三种，放在证件背包中。
- **装备**：玩家把持有卡放进两个装备槽之一。没有装备的第三张卡仍保留，不会丢失。
- **当前身份**：两个槽中只有一个当前生效。Q 切换槽位；工作和普通身份门主要检查这张卡。

背包中可把收藏证件拖到A／B槽，也可继续使用原装备按钮和键盘。替换仍由CardManager核验；被替换的卡留在收藏，不直接从收藏生效。首次取证提示I，两槽可用时提示Q；新获得但未装备的证件提示拖拽替换。角色按当前实际身份显示保洁头巾／保安帽／经理西装上衣，并保留短提示；空身份恢复原样。经理不换原棕裤、靴子和红挎包，旧胸前卡牌图标移除。当前槽被移空时会提示Q启用另一槽。

前两张卡取得时可进入空槽；取得第三张卡后，玩家需要通过 I 替换装备槽，再用 Q 选择当前身份。因此“包里有经理证”不等于“现在以经理身份工作”。

双卡任务同时检查指定两卡已装备，但每一步仍只有一个生效身份。例如 204 要两槽装备保洁＋保安，清理时当前是保洁，领记录和交付时当前是保安。不能用两张任意卡代替，也不能只持有而不装备。

### 偷证

当前任务接取后，才允许取得该任务需要、尚未持有的员工证件，不能在开局把三张卡提前偷齐。

合资格员工靠近时显示实际背后站位标记，随员工转身变化；正面提示风险，持有证件后不再提示重复偷取。

玩家需靠近员工身后、站定并长按 E 约 **0.8 秒**。距离、面向、员工转身和偷窃中的状态会影响结果；从正面偷或偷到一半被发现会触发当前任务失败。员工的好奇、转身等行为需要观察，好奇提示本身不直接等于失败。

任务完成后已获得证件保留，后续可以重复使用。正常流程到三楼时已有经理证，不需要再偷一次。

## 5. 工作类型和资格

| 类型 | 操作                | 必要条件                    |
| -- | ----------------- | ----------------------- |
| 清理 | 站定、长按 E **1.5 秒** | 当前保洁身份、对应任务已接、正确污渍与步骤   |
| 领取 | 站定、按 E            | 当前为工作点要求的身份、任务资格和前置步骤成立 |
| 批准 | 站定、按 E            | 当前经理身份、对应申请／文件已满足条件     |

长按清理有进度反馈。松开、移动、切换身份或进入模态界面会中断本次操作，不能把多个中断的长按当成已经完成。

工作不是单纯播放动画：系统核对活动任务、真实工作点、楼层、顺序、当前身份、必要装备和剩余时间，再记录成果。204 的污渍与 201 独立；205 的备案与最终离店许可独立。

包裹、巡房记录、通行单目前通过任务成果状态记录，没有额外的通用物品管理系统。

## 6. 二楼五怪教学的实际任务

以下五项按 201 → 202 → 203 → 204 → 205 顺序推进；上一项真实交付后下一项才开放。时限从点击接受开始，**工作做完后返回交付也消耗剩余时间**。

| 房间／怪物   | 工作身份与时限         | 实际流程                                              | 放行条件                     |
| ------- | --------------- | ------------------------------------------------- | ------------------------ |
| 201 长鼻客 | 保洁；120 秒        | 接任务 → 回一楼偷保洁证 → 保洁身份清理二楼原污渍 → 返回 201              | 原污渍清理成功，当前保洁身份真实交付       |
| 202 独眼客 | 保安；120 秒        | 接任务 → 回一楼偷保安证 → 保安身份在二楼包裹柜领取 → 返回 202             | 真实取得包裹，当前保安身份交付          |
| 203 礼帽客 | 经理；120 秒        | 接任务 → 回一楼偷经理证 → I 替换槽／Q 切经理 → 在二楼房务登记台批准 → 返回 203 | 房务申请批准，当前经理身份交付          |
| 204 大耳客 | 同时装备保洁＋保安；210 秒 | 保洁清理 204 独立污渍 → 切保安领取巡房记录 → 返回 204                | 两种工作按序完成，两卡仍装备，当前保安身份交付  |
| 205 核验客 | 同时装备保安＋经理；210 秒 | 保安领取待审通行单 → 在安全工作区切经理批准 → 返回 205                  | 领取和批准按序完成，两卡仍装备，当前经理身份交付 |

203—205 的时限是调试初值，尚未做新流程的真人节奏校准。

### 201 与 202

保留已经建立的偷保洁证、原污渍、取包裹与返回交付链，复用真实怪物对白面板。201 的完成记录不能替代 204 的清理；202 的领取不能替代其他领取任务。

### 203 与三楼登记的区别

203 是**二楼房务申请**。它让玩家取得和使用第三张工作证，并返回礼帽客交付。它不会批准 309 登记，也不会提前开 309。

### 204 的两种工作

204 必须先清理独立污渍，再领取巡房记录。只完成一项、只切两次卡、用 201 已清理的结果，均不算完成。双卡要求在工作步骤和交付时核验。

大耳客对应的普通规则是“门开时不能移动”，但当前二楼教学主要是两种工作链，尚不能说已经形成完整的听觉／停步挑战。这是值得继续讨论的设计缺口。

### 205 与安全区换证

205 的领取点和批准点分开布置，两个工作地点均位于核验客危险半径外。玩家在安全区域准备双卡和切换身份，不能在核验客门前临时换证。

当前二楼核验范围内，I 和 HUD 背包入口都会被阻止；Q 换证仍会产生违规。违规没有解除时不能靠交付或换层跳过，需要退离范围后再处理。

205 只是**二楼通行备案**。它不等于最终离店许可，不解锁 EXIT，也不代表救援完成。

## 7. 门、怪物显示与回访

### 二楼首次教学门

五种怪物固定对应 201—205，首次不随机。玩家接近可接任务的门时，先经历约 **1.5 秒预警**，再开门展示实际怪物并触发对白。接近触发距离约 210 像素，剧情交互范围约 120 像素，均是当前可调参数。

未完成任务的住客会留在门口，回访和重试不应反复重播首次警报。对白使用 D 的同一套怪物面板，并显示当前正在说话的实际怪物；对白期间不会同时展示另一扇说话门。

接任务后仍有通路限制。203—205 的工作点在对应门前侧；玩家完成工作但未交付时，仍不能直接越过任务门。只有真实交付成功才结算并解除限制，随后播放成功反馈。关闭对白没有结算效果。

任务完成并结束对白后，该教学门关闭。再次经过不会自动重复拦截；主动按 E 回访可显示完成后的短对白，不会重新发奖或再接同一任务。

### 回访对白按真实进度选择

| 真实状态         | 应得到的反馈                   |
| ------------ | ------------------------ |
| 没有证件／未装备指定双卡 | 提醒准备证件或调整装备              |
| 已有正确证件但工作未做  | 指明具体工作点和当前目标             |
| 双工作只做完第一步    | 提醒剩下的步骤，不能放行             |
| 工作全部完成       | HUD 指向返回对应房间；E 尝试交付并复核身份 |
| 已经真实交付       | 成功对白／完成回访，不重复结算          |

“见过怪物”和“完成该任务”分别记录，不能把见面或关闭对白当作教学通过。

### 三楼以上的普通门

普通房间从五怪类型中分配，分配结果在本局内保持稳定；新局可以变化。随机的是普通门的怪物配置／开门调度，地图本身不随机。302 等固定主线任务门仍有独立接线，不会再承担二楼同一项首次教学。

普通门使用预警、开门、关闭与冷却的调度；同一楼层避免普通门同时开门。玩家观察实际门内怪物来决定身份或等待，不应只依赖一张固定剪影。

| 怪物  | 普通门当前规则                |
| --- | ---------------------- |
| 长鼻客 | 检测范围内需要当前保洁身份          |
| 独眼客 | 检测范围内需要当前保安身份          |
| 礼帽客 | 检测范围内需要当前经理身份          |
| 大耳客 | 开门检测范围内不能移动；停下并等待关门再经过 |
| 核验客 | 开门检测范围内禁止换证；应提前在安全区准备  |

普通检测半径当前约 **90 像素**。剧情门的接取、工作、交付生命周期有专门处理，不能直接把普通门检测表当作每个教学步骤的完整规则。模态界面内换装与所有普通核验门的边界还需继续验收，不能视为全部解决。

## 8. 任务计时、失败与重试

同一时间只有一个当前任务，主要状态如下：

> 可接取（未计时）→ 接受并进行（计时）→ 工作完成、待交付（仍计时）→ 交付完成（停表）。

对白、手册／笔记、背包、暂停界面停止任务计时。单纯显示世界内工作提示不会停表。任务详情、HUD、检查点和失败反馈按当前任务读取，不能继续固定显示 201 的说明。

### 被员工发现或超时

触发当前任务失败，打开失败界面。点击重试后回到该任务**接取前的检查点**，需要重新接受才重新开始完整倒计时。

- 保留接取前已完成的任务、证件、装备和故事进度。
- 恢复接取前的楼层与安全位置、已到达楼层及本局怪物记录等状态。
- 撤销本任务中新取得的证件和工作成果；双工作不会保留刚才完成的一半。
- 不抹掉前序任务的成果，也不把玩家直接恢复到全新游戏。

例如第一次做 203，失败后这次新偷的经理证会按检查点回滚；做 204 失败则保留此前 201—203 已经取得的三证，但撤销 204 的独立污渍和巡房记录成果。

### 普通门违规

普通门用错身份、在大耳门前移动等违规，当前处理为警告并退回**当前楼层左侧楼梯记忆点**，保留证件、任务、世界成果和倒计时，不进入上述任务检查点重试。

两种惩罚强度不同：员工发现／超时重做当前任务；普通门违规主要损失位置和行走时间。具体公平性与反馈清晰度仍适合试玩讨论。

从菜单重新开始游戏会清空本局状态并重播序章，不是继续上次检查点。这里的检查点是本局失败恢复机制，不应据此理解为已经有跨启动存档。

## 9. 楼层推进、三楼登记与 309 救援

| 阶段        | 当前解锁条件与用途                       |
| --------- | ------------------------------- |
| 一楼 → 二楼   | 完成一楼经理介绍对白，不要求先拿齐三证             |
| 二楼 → 三楼   | 201—205 五项教学全部真实交付              |
| 三楼 302    | 接独立的 309 登记授权任务，120 秒           |
| 309 登记台   | 当前经理身份批准，立即完成授权任务并停表，无需回 302 报告 |
| 进入 309 救援 | 已完成三楼授权、登记已批准，且当前为保洁身份          |
| 救援完成 → 四楼 | 309 重逢对白完整结束后，救援结算、Terese同行，允许上四楼  |
| 四楼 → 五楼 | 救援完成，在403接受120秒任务，背后长按E偷真实巡房文件并返回403交付 |
| 五楼 → EXIT | 在501接受180秒任务，当前经理批准并返房交付，再到实际出口按E；仍核验救援及后段成果 |

302介绍先说明当前经理到本层登记台批准；实际批准后才提示切保洁到309按E，不在第一次对白堆叠全部步骤。

309 使用已接入的重逢 CG／对白。只有最后完成回调才写入救援成功；打开、预览或取消对白不能代记救人。Terese随后作为视觉跟随角色同行，没有独立碰撞或另一套怪物受击判定。

救援后封锁一楼和二楼，可回访已经到达的三至五楼。新楼层按 403、501 和 EXIT 流程逐步推进。

## 11. 优先讨论的设计问题

以下是基于现有结构的讨论方向，**尚未采用，也尚未修改玩法**。

### 11.1 后三项容易重复

203 批准申请、204 清理加取记录、205 取单加批准，目前主要组合已有工作动作。玩家可能觉得一直是走到工作台、按 E、走回门口，怪物差异没有充分转化成操作差异。

希望讨论：能否保持真实工作和返回交付约束，同时让每关多一个不同的观察或决策，而不是增加更多跑腿步骤？

### 11.2 204 的怪物特征与任务联系偏弱

大耳客普通规则强调不动／安静，但当前教学重点仍是清理和领取。可讨论把清理变短，把保安读取记录与停步、观察开门时机结合。需要明确挑战发生在哪里，不能只改对白就宣称教会了听觉规则。

### 11.3 205 应突出安全准备

205 已解决工作点靠近核验区的问题，但领取、找批准台、切卡和返回仍可能让玩家迷路。可以讨论把两个步骤做成一个清晰工作区域中的分阶段操作，保留双证与安全区换证要求。当前实现仍是两个分开的工作点。

### 11.4 203 与 309 的重复授权

二楼房务批准与三楼 309 登记在状态上已经分离，叙事上仍需解释“为什么还要再批准一次”。可考虑让 203 重点教第三卡装备并给出 309 线索，让三楼授权有明确的新目的；这只是提案。

### 11.5 时间压力和重试成本

任务需要跨楼拿卡、工作、返房，而且做完工作仍计时；失败会撤销本任务成果。应通过真人试玩判断时限是否合理、缺证提示是否足够、失败原因是否可读，特别是第三卡装备与双工作任务。尚不能根据自动化跑通就认定时限平衡。

### 11.6 提示要说明下一步，而非一次说太多

玩家需要快速看懂：当前身份、已装备哪两张卡、完成到哪一步、下一地点、是否需要返回交付、哪里可以安全换证。希望用阶段性短提示减少反复打开长对白，而不是另做一套 UI。

## 12. 团队分工与修改成本

| 负责人 | 主要范围                       | 讨论方案应注意                 |
| --- | -------------------------- | ----------------------- |
| A   | 主角、楼层、任务真值、计时、检查点、救援、主场景整合 | 任务顺序和解锁集中管理，不分散在多个界面保存  |

方案最好先给出可在现有组件上完成的小改动，再列需要新增素材或结构改动的备选。不要默认所有人同时修改主场景或同一个管理器。

## 13. 现有验证与局限

main原合并记录有49项检查；本轮A后段整合最新51项按影响复查通过，另有正常新局至EXIT整链与原生Compatibility后段画面检查通过。来源与初跑／复查见[后段交接](late_mainline_handoff_20261121.md)。

五怪自动流程从正常菜单开始，实际调用员工偷证、工作点、装备和交付；但位置、员工朝向、怀疑阶段和时钟存在明确的测试控制。309 原生检查也使用了前置状态准备。它们证明接线和边界，不等于无辅助真人完整通关，也不等于实际等待每个完整时限的人工验收。

原 201 真人六项、202 成功与超时的用户验收保留；不能迁移为新版 203—205 或 309 已通过真人验收。完整英文、Windows、新时限节奏和最终逃脱仍需后续验证。

继续完善时，至少应检查缺证、错误当前身份、双卡未装备、只完成一项工作、工作完成未交付、超时／被抓重试、完成后回访，以及 203／204／205 不误写 309 或最终离店进度。
