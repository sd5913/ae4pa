## 2 固定标识和归属

任务 ID 为 `TASK_01_CLEAN`、`TASK_02_PARCEL`、`TASK_03_AUTHORIZE`、`TASK_04_PATROL`、`TASK_05_EXIT`。首轮物件为 `STAIN_201`，完成事实为 `stain_201_cleaned`；员工来源为 `STAFF_CLEANER_1F`，卡仍用 B 的 `CLEANER`。剧情房间用 201，楼层标识使用整数 1—5。其余对象 ID 在 [接口 §13](interfaces.md#13-v4-目标接口提案尚未实现) 保持同一拼写，后续对应里程碑再落地。

- A 的 GameManager 保存任务、倒计时、故事、楼层与世界事实。B 的 CardManager 唯一保存卡拥有／装备／当前槽；B 员工和工作点产生已验证的交互请求。C 门检测并请求剧情拦截或普通退回。D 只显示快照、打开模态和发操作请求。
- `E` 由当前楼层选择唯一最近合法目标：剧情／交付点、可操作员工或工作点、楼梯、普通提示；长按只由被选中的 B 组件处理。`Q` 由 B 的 CardManager 处理；`I` 和笔记／暂停由 D 接收，A 管任务停表。不能让同一个 `E` 同时被楼梯、员工和房门消费。
- C 的普通门违规不能继续调用当前 `GameManager.fail()` 作为 V4 正式后果。B 员工在有效任务内被抓，应请求 A 的任务失败；无活动任务时不能开始偷窃，E 只提示，因此不进入偷窃被抓流程。

## 4 最小调用链

1. D 的经理对白完成通知 A；A 记录 `manager_intro_finished`。玩家在 1F 楼梯按 E，A 校验真实位置与允许楼层后载入 2F。
2. C 的 201 固定触发区请求 `TASK_01_CLEAN`。A `offer_task` 核对前置、楼层及无其他任务，发任务介绍；此时不扣时。D 的接受请求调用 `accept_task`；A 应先保存任务前检查点，随后设 ACTIVE 与 210 秒。当前 A 仅实现状态与计时，检查点待 B 卡快照。
3. A 允许玩家回 1F。B 保洁员工验证身后长按与任务资格，成功后只由 CardManager 授 `CLEANER`。回 2F 时任务与秒数不重置。
4. B 污渍点验证距离、长按及当前 `CLEANER`，向 A 发 `STAIN_201` 成功请求。A `record_work_result` 再查任务、楼层、当前卡和去重，写 `stain_201_cleaned`，状态变待交付；倒计时继续。
5. 玩家回 201，C 发交付请求，A `submit_task` 检查任务和清洁事实后立即结算；D 再播放后续对白。A 记录永久完成与通路许可，重复 E 不再奖励。
6. 员工被抓或超时由 A 进入任务失败。正式重试依 A-V4-04、B 卡片快照恢复接取前状态；普通门违规经安全退回，不执行任务回滚。

A 对外提供 `is_interaction_allowed(target_id: String) -> bool` 作为任务资格查询；B 在长按开始和奖励结算前各查询一次，自己另查范围、朝向、移动与是否已取。A 只返回资格，不代替 B 判定偷窃成功。任务 AVAILABLE、FAILED、COMPLETED 或无任务时不能偷取该任务奖励；已拥有的卡不能再触发长按。当前 A 代码尚未实现这个查询，B 不应把本表当作已可调用接口。

### 6.2 E 键唯一归属

正式楼层由 A 选择一个世界目标并消费 E：先让 D 模态页面处理，再按当前可交付／剧情、工作／员工、楼梯的优先级挑目标；同级取距离最近者，平局按固定目标 ID。按下时锁定目标，按住期间不切到旁边组件，松开、离开范围、移动、换卡、开页面、失败或换层时取消。B 员工／工作点暴露 `begin_steal`／`cancel_steal` 或对应工作方法，不在正式楼层各自用 `_unhandled_input` 抢 E。B 的独立 F6 可保留测试输入适配层，但主线接入时只走 A 路由；A 负责提供可用目标和转发按下／松开。

### 6.3 卡片快照与任务失败恢复

B 的 `export_snapshot() -> Dictionary` 返回深拷贝，固定键为 `owned_cards: Array[String]`、`equipped_cards: Array[String]`（恰好两槽）、`active_slot: int`（0 或 1）。`restore_snapshot(snapshot: Dictionary) -> bool` 先完整验证卡 ID、重复项、槽位和拥有关系；无效输入返回 false 且不改任何卡状态。有效输入一次性替换卡数据，发一次 `cards_changed`，不发 `identity_changed`，也不逐张调用 `collect_card`／`equip_card`。

A 在玩家确认接受任务之前保存 B 导出的快照，以及接取层、任务／世界／故事状态；保存成功才进入 ACTIVE 并开始完整计时。员工被抓或超时后先进入 FAILED，D 的“重新挑战本任务”请求交给 A：关闭模态、取消长按和旧场景事件，恢复 B 卡与 A 世界事实，重载接取层安全点，回到 AVAILABLE 且剩余时间为 0；再次点击接受才重新计满时限。任务 01 重试撤销本次保洁卡与污渍，任务 02 以后保留此前已交付任务的卡与许可。普通门警告退回不调用快照恢复。
