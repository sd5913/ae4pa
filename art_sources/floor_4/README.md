# 四楼分层美术源文件

以用户确认的青绿色雅致酒店效果图为布局和风格参考；门不制作，门位保持完整墙面供已有门组件覆盖。无场景人物、水管、清洁工具或工具柜。

- `floor_4_layers.ora`：7680×1280 OpenRaster，可用 Krita/GIMP 打开，4 分组、30 个可移动组件图层。不是仅包含预览的扁平文件。
- `approved_reference.png`：已确认效果图，仅作参考，不放大作为成品底图。
- `generated/`：13 个独立生成组件的原生 PNG；`prompts.json` 保留内置 imagegen 提示词。生成细节以参考稿为准，非对总图逐像素机械裁切。
- `preview.png` / `preview_small.png`：无房门组件拼接预览。
- `validation.json`：真实 Alpha、分区拼回、重复边缘与 ORA 重建的实际检查结果。

为统一各层风格，整体楼梯、完整黑柱、顶梁、外景及通用光晕/阴影复用已确认三楼组件；来源逐项记录在游戏素材目录的 `layout.json`。两侧楼梯的栏杆包含在整体楼梯 PNG 中。确认稿没有窗，不额外添加窗框或改变房间布局。

游戏用 PNG 在 `../../assets/final/floor_4_layers/`：原生尺寸或缩小后组装，不将整层小图放大；墙面、地毯采用原生纹理重复拼接。墙纸/地毯使用镜像重复片确保两端像素一致，底部踢脚线单独输出。

透明物件保留真实 RGBA Alpha，透明留白不是黑底或棋盘格。画像里的静态装饰侧影保留；家具亮部烘焙在材质内，可叠加的灯光与接触阴影另有独立效果层。ORA 与合成预览使用普通 Alpha 混合；`layout.json` 提供可选 screen/multiply 建议，未假称这些引擎混合模式已接入游戏。

只交付美术，未替换四楼场景或改动任务/门逻辑。门位尺寸仅作布局参考；后续叠加已有门组件时保持其原宽高比，按实际遮挡适当调整邻近家具。
