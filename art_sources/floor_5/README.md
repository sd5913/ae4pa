# 五楼分层美术源文件

依据用户提供的五楼参考图按物件重绘和分区拼接，保留原楼层的酒红金色、左休息区、屋顶徽章/半圆窗、离店登记区和右出口。去除登记员及出口处两个人物，排除全部房门与门附带灯具。房门位置保留连续墙面，以便使用已经生成的门组件。

- `floor_5_layers.ora`：7680×1500 OpenRaster，4组44层，可用Krita/GIMP逐层编辑，包含独立物件及位置/透明度，不是只有合成图的扁平文件。
- `generated/`：17个内置imagegen生成组件的原生PNG。`prompts.json`记录提示词及对应生成图。参考图不放大作为成品底图。
- `reference.png` / `reference_strip.png`：原参考及裁带，仅用于对照布局；其中的原房门/人物不属于成品。
- `preview.png` / `preview_small.png`：无房门、无人物的组装预览。
- `alpha_contact.jpg`：浅色背景的透明组件检查表，不用于游戏。
- `validation.json`：RGBA、拼接、重复边缘和ORA重建的实际验证记录。

外景、完整黑柱、左整体楼梯、顶梁、灯桌、盆栽和通用光影复用已确认三楼组件以统一风格，来源逐项记录在 `../../assets/final/floor_5_layers/layout.json`。楼梯栏杆属于楼梯整体PNG。右出口包含空拱口、EXIT牌、小窗、整个平台及栏杆，不包含门扇或人物。

透明外缘与栏杆/出口空隙均保留真实Alpha，没有绘制黑底或棋盘格。窗内绘制的紫色外景是玻璃视景的一部分。家具亮部可保留在材质中，额外光晕和接触阴影独立成层。ORA及普通预览采用标准Alpha合成，layout.json另给可选screen/multiply建议，未宣称已接入引擎混合模式。

屋顶的中央徽章/双扇形窗、左右重复栏杆檐口、通长扶手顶条、柱头分别保留；墙纸、地毯、踢脚线均可重复铺排。原生图仅裁透明留白、裁取纹理或等比缩小使用，未放大整栋楼参考图。家具底边按实体脚底对齐，花瓶落在登记台台面。
